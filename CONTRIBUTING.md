# Contributing to Copilot Planning-with-Files

Thank you for your interest in contributing!

## How to Contribute

### Reporting Issues

- Use GitHub Issues
- Include VS Code version, Copilot version
- Provide steps to reproduce
- Share relevant file contents if applicable

### Suggesting Features

- Open a GitHub Issue with [Feature Request] tag
- Describe the use case
- Explain how it improves the planning workflow

### Submitting Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Test in a real project (dogfood it!)
5. Update documentation if needed
6. Commit with clear messages
7. Push and create a Pull Request

## Code of Conduct

- Be respectful and constructive
- Help newcomers
- Focus on improving the planning methodology

## Testing Your Changes

Before submitting:

1. Test .github/copilot-instructions.md loads properly
2. Verify /plan, /update-plan, /check-complete commands work
3. Test Agent Skill activates correctly
4. Review all template enhancements
5. Check documentation for accuracy

## Documentation Standards

- Keep examples practical and realistic
- Use clear, concise language
- Include code blocks with proper syntax highlighting
- Cross-link related documents

## What We're Looking For

Contributions that:
- Improve Copilot-specific integration
- Enhance template clarity
- Add helpful examples
- Fix bugs or typos
- Improve documentation

## What We're NOT Looking For

- Multi-IDE support (see original planning-with-files repo)
- Complex scripts (Copilot is meant to be simple)
- Features that break the core 3-file pattern
- Additions that require plugins

## Questions?

Open an issue or start a discussion!
